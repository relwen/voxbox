# Voxy Box - Documentation du Projet

## 📱 Qu'est-ce que Voxy Box ?

**Voxy Box** est une application mobile conçue spécialement pour les chorales et leurs membres. Elle permet de centraliser, organiser et partager tous les éléments nécessaires à la pratique du chant choral : partitions musicales, enregistrements audio, vocalises d'échauffement, et bien plus encore.

L'application facilite la vie des choristes en leur donnant accès à tous leurs documents musicaux au bout des doigts, que ce soit pour répéter à la maison, apprendre de nouveaux morceaux, ou se préparer aux répétitions.

---

## 🎯 Objectif du Projet

### Problème résolu

Avant Voxy Box, les choristes devaient :
- Gérer des piles de partitions papier
- Partager des fichiers audio par email ou messagerie
- Se coordonner manuellement pour distribuer les partitions
- Perdre du temps à chercher les bonnes versions de fichiers
- Faire face à des problèmes d'organisation entre les différents pupitres (Soprano, Alto, Ténor, Basse)

### Solution apportée

Voxy Box centralise tout dans une seule application :
- **Accès instantané** à toutes les partitions de la chorale
- **Organisation par pupitres** : chaque choriste voit uniquement ce qui le concerne
- **Enregistrements audio** pour apprendre sa partie
- **Vocalises** pour s'échauffer avant les répétitions
- **Synchronisation automatique** : les nouvelles partitions apparaissent pour tous les membres
- **Fonctionnement hors ligne** : téléchargez vos partitions et écoutez-les même sans internet

## 🎵 Fonctionnalités Principales

### 1. Gestion des Partitions

Les choristes peuvent :
- **Consulter** toutes les partitions de leur chorale
- **Télécharger** les partitions pour les consulter hors ligne
- **Voir les partitions** au format PDF ou image
- **Organiser** les partitions par catégories
- **Rechercher** rapidement une partition spécifique

### 2. Gestion des Messes

Pour les chorales religieuses, l'application permet de :
- **Organiser les messes** par sections (Kyrié, Gloria, Sanctus, Agnus Dei, etc.)
- **Associer des partitions** à chaque section de messe
- **Ajouter des enregistrements** pour chaque partie de la messe
- **Organiser par pupitres** : chaque pupitre voit ses propres fichiers
- **Synchroniser** les nouveaux éléments avec toute la chorale

### 3. Vocalises et Échauffements

Les choristes ont accès à :
- **Des vocalises** organisées par pupitre
- **Des enregistrements audio** pour s'entraîner
- **Des exercices** adaptés à chaque voix (Soprano, Alto, Ténor, Basse)
- **La possibilité d'ajouter** leurs propres vocalises

### 4. Enregistrements Audio

L'application permet de :
- **Enregistrer** sa propre voix pour s'entraîner
- **Écouter** les enregistrements de référence
- **Partager** des enregistrements avec la chorale
- **Organiser** les enregistrements par pupitre et par morceau

### 5. Organisation par Pupitres

Chaque choriste voit uniquement :
- **Les partitions** de son pupitre (Soprano, Alto, Ténor, Basse, etc.)
- **Les enregistrements audio** spécifiques à sa voix
- **Les vocalises** adaptées à son pupitre
- **Les fichiers généraux** (partitions complètes, images, PDFs) accessibles à tous

### 6. Créations Personnelles

Les choristes peuvent :
- **Créer des dossiers** pour organiser leurs enregistrements
- **Enregistrer des audios** directement depuis l'application
- **Prendre des photos** de partitions
- **Uploader des fichiers** (audio, PDF, images)
- **Synchroniser** leurs créations avec le reste de la chorale

### 7. Recherche

L'application offre :
- **Recherche globale** dans toutes les partitions
- **Recherche dans les vocalises**
- **Recherche dans les messes**
- **Filtrage** par catégorie, pupitre, ou type de fichier

## 🎼 Concepts Clés

### Chorale

Une chorale est un groupe de chanteurs. Chaque chorale a :
- Un nom et une description
- Des membres (les choristes)
- Des partitions partagées
- Des messes organisées (pour les chorales religieuses)

### Pupitre

Un pupitre représente une voix dans la chorale :
- **Soprano** : voix aiguës (généralement féminines)
- **Alto** : voix moyennes (généralement féminines)
- **Ténor** : voix moyennes (généralement masculines)
- **Basse** : voix graves (généralement masculines)
- **Tutti** : pour tous les pupitres ensemble

Chaque choriste appartient à un pupitre et voit uniquement les partitions et fichiers qui le concernent.

### Partition

Une partition est un document musical qui peut contenir :
- Des images de partitions
- Des fichiers PDF
- Des enregistrements audio
- Des fichiers organisés par pupitre

### Messe

Une messe est une œuvre musicale religieuse organisée en sections :
- **Kyrié** : première partie de la messe
- **Gloria** : deuxième partie
- **Sanctus** : troisième partie
- **Agnus Dei** : dernière partie

Chaque section peut contenir plusieurs partitions et enregistrements, organisés par pupitre.

### Vocalise

Une vocalise est un exercice vocal utilisé pour :
- S'échauffer avant les répétitions
- Améliorer la technique vocale
- S'entraîner sur des passages difficiles

Les vocalises sont organisées par pupitre pour s'adapter à chaque type de voix.

## 🔄 Synchronisation

L'application fonctionne avec un système de synchronisation intelligent :

1. **Synchronisation automatique** : Les nouvelles partitions et fichiers ajoutés par le directeur de chorale apparaissent automatiquement pour tous les membres

2. **Fonctionnement hors ligne** : Les choristes peuvent télécharger leurs partitions et les consulter même sans connexion internet

3. **Mise à jour en temps réel** : Lorsqu'un membre se connecte, l'application vérifie automatiquement s'il y a de nouveaux contenus disponibles

4. **Partage facile** : Les enregistrements et fichiers créés par les membres peuvent être synchronisés avec toute la chorale

## 🎯 Cas d'Usage

### Scénario 1 : Apprendre une Nouvelle Partition

1. Le directeur de chorale ajoute une nouvelle partition dans l'application
2. La partition est automatiquement synchronisée avec tous les membres
3. Chaque choriste reçoit la partition de son pupitre
4. Les choristes peuvent télécharger la partition et l'enregistrement audio
5. Ils peuvent s'entraîner à la maison avant la répétition

### Scénario 2 : Préparer une Messe

1. Le directeur organise les partitions par sections de messe (Kyrié, Sanctus, etc.)
2. Il ajoute des enregistrements pour chaque section et chaque pupitre
3. Les choristes voient uniquement les partitions de leur pupitre
4. Ils peuvent écouter les enregistrements pour apprendre leur partie
5. Le jour de la messe, tout le monde est prêt

### Scénario 3 : S'Échauffer Avant une Répétition

1. Un choriste ouvre l'application avant la répétition
2. Il accède à la section "Vocalises"
3. Il sélectionne des vocalises adaptées à son pupitre
4. Il écoute les enregistrements pour s'échauffer
5. Il arrive à la répétition prêt à chanter

### Scénario 4 : Partager un Enregistrement

1. Un choriste enregistre sa voix pour s'entraîner
2. Il décide de partager l'enregistrement avec la chorale
3. Il synchronise l'enregistrement depuis l'application
4. Tous les membres de la chorale peuvent maintenant écouter cet enregistrement
5. Cela aide les autres choristes à apprendre leur partie
